
# Portfolio 2

A personal portfolio project built with Vue and Vite.

**Created:** September 2026

## Built With

* Vue
* Vite
* JavaScript
* CSS

## Getting Started

```bash
git clone https://github.com/gMieFE/portfolio-2.git
cd portfolio-2
npm install
npm run dev
```

The application will run locally using the Vite development server.

## About

A personal project created to practice and showcase frontend development skills with Vue.
